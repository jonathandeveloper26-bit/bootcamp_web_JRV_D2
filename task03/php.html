PHP

PHP is a general-purpose scripting language geared towards web development. It was created by Danish-Canadian programmer Rasmus Lerdorf in 1993 and released in 1995. The PHP reference implementation is now produced by the PHP Group. PHP was originally an abbreviation of Personal Home Page, but it now stands for the recursive backronym PHP: Hypertext Preprocessor. - Wikipedia

My Thoughts

  • PHP is a server-side scripting language: code runs on the web server and sends only the resulting HTML to the browser.

  • PHP code goes inside tags (often mixed into HTML), variables start with $, and statements end with ;

  • PHP is loosely typed, so use === instead of == to avoid surprising automatic type conversions.

  • PHP powers most of the web (WordPress, Wikipedia, Laravel, the LAMP stack), and PHP 8 is the current major version.
